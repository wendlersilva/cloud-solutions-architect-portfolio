# ☁️ Cloud Solutions Architect Portfolio

Laboratórios práticos de arquitetura em nuvem com foco em **Amazon Web Services (AWS)**.

Este repositório documenta minha jornada de aprendizado para me tornar um **Cloud Solutions Architect**, através de laboratórios práticos envolvendo infraestrutura em nuvem, redes, segurança, escalabilidade, disponibilidade, armazenamento, computação, bancos de dados e outros conceitos fundamentais de arquitetura Cloud.

Cada laboratório é documentado para demonstrar não apenas **como** a solução foi implementada, mas também **por que** determinadas decisões arquiteturais foram tomadas.

---

## 🎯 Objetivos

Os principais objetivos deste portfólio são:

- Desenvolver habilidades práticas em arquitetura Cloud
- Adquirir experiência prática com serviços AWS
- Compreender padrões e boas práticas de arquitetura
- Praticar o desenvolvimento de soluções seguras, escaláveis e resilientes
- Documentar decisões técnicas e seus motivos
- Construir um portfólio prático de projetos de arquitetura Cloud
